# @motionmeet/backend

MotionMeet backend server built with Node.js, Express.js, and MongoDB.

## Getting Started

```bash
npm run dev
```

The server will start on `http://localhost:5000`

## Environment Variables

Create a `.env` file:

```
PORT=5000
MONGODB_URI=mongodb://localhost:27017/motionmeet
NODE_ENV=development
```

## Testing

```bash
npm test
```
